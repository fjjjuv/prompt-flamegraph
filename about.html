About

Built to make prompt token usage visible, debuggable and cheap.

Why it exists

When a prompt contains tools, RAG chunks and a long chat history, the token bill becomes a black box. prompt-flamegraph turns that black box into a picture you can reason about.

Design principles

  • No required dependencies
  • No server, no telemetry, no proxy
  • One function call, one output file
  • Pluggable tokenizers
  • Open source under GPL-3.0

When to use it

  • Your prompts keep growing and you do not know why
  • You want to compare two prompt versions
  • You suspect duplicate context or too many tools
  • You need to explain token cost to a teammate
